# Exercícios Java

Esse repositório possui alguns exercícios simples em Java.

## Exercícios

### Exercício 1
Lista de compras usando ArrayList.

Funções:
- Adicionar produtos
- Mostrar produtos
- Mostrar quantidade total

---

### Exercício 2
Sistema de notas usando ArrayList<Double>.

Funções:
- Adicionar notas
- Calcular média
- Mostrar situação da turma

---

### Exercício 3
Lista de presença usando HashSet.

Funções:
- Adicionar alunos
- Evitar nomes repetidos
- Mostrar quantidade de alunos

---

### Exercício 4
Cadastro de alunos usando HashMap.

Funções:
- Cadastrar matrícula
- Buscar aluno
- Remover aluno
- Mostrar lista

---

### Exercício 5
Fila de atendimento usando Queue.

Funções:
- Adicionar clientes
- Mostrar próximo cliente
- Atender clientes
- Atualizar fila

---

### Exercício 6
Sistema simples de biblioteca.

Funções:
- Cadastrar livros
- Listar livros
- Emprestar livros
- Devolver livros

Tecnologias usadas:
- ArrayList
- Classe Livro
- Scanner

---

### Exercício 7
Sistema de pedidos de lanchonete.

Funções:
- Cadastrar pedidos
- Atualizar status
- Buscar pedidos
- Calcular valor total

Status:
- PENDENTE
- PREPARANDO
- FINALIZADO

Tecnologias usadas:
- ArrayList
- Classe Pedido
- Scanner

---

## Tecnologias usadas
